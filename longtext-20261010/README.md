# 联合微调长文本测试

本轮复用已完成的 GPT 42 步、CFM 84 步适配器，没有继续训练。测试日常叙述、多段说明、长篇故事三段新文本，并对最长故事增加较短分段的联合微调版本。原始底座和联合适配器使用同一参考、相同随机种子与采样参数。

[打开长文本试听](listening.html)。每段原文和完整音频均已保留，分段音频也在 `audio` 子目录中。

最长原文 756 字含标点，联合微调默认 120 token 分段输出 151.2 秒，60 token 分段输出 182.3 秒。音频与保存的各段 PCM 加 200ms 静音逐采样一致。自动复核没有发现大段漏读或重复追加的证据；音色、语速与衔接需要人工试听。此次长篇分数没有显示联合微调稳定优于底座，不能把短句的提升直接推广到长篇。

CER 是 Whisper turbo 自动转写与目标文本的字符编辑距离，越低越好。整段 CER 衡量拼接后的完整音频；逐段 CER 排除长音频转写分窗造成的部分影响。原文全部使用中文，没有数字展开计分问题；同音字、转写错字和音频发音错误仍不能由单一 ASR 完全区分。`metrics.json` 保留逐段原文、转写、插入/删除/替换计数。

最后一段的错误率用于辅助检查句尾完整性，不等于人工认定没有截断。没有进行人工听感评审，不能仅凭自动分数判断段落衔接自然或情感表达稳定。

## 长篇识别异常复核

上表保留第一次识别的原始结果。最长联合微调 120 token 版本整段 CER 为 18.81%，其中 112 次插入主要来自转写结尾追加的“请不吝点赞”“转发”等重复文字；逐段识别没有这些追加。完整音频逐采样等于分段拼接，因此也不存在拼接后额外追加的音频。

| --- | ---: | ---: | ---: | ---: |
| 原始底座 / 120 token | 2.52% | 16 | 1 | 0 |
| 联合微调 / 120 token | 3.11% | 20 | 1 | 0 |
| 联合微调 / 60 token | 2.81% | 19 | 0 | 0 |

异常的重复追加消失，支持这是识别器尾部幻觉的判断。独立 SenseVoiceSmall 对联合微调 120 token 的全部七段复核，逐段合计 CER 为 3.26%，最后一段为 1.64%，同样覆盖故事结尾。所有复核转写在 `asr-diagnostics.json` 中。

60 token 版本在首次逐段识别中错误率较低（2.37% 对 3.41%），但时长增加约 31 秒、段数从 7 增至 15。可作为较短分段的试听对照；本次只测试一篇故事，尚不足以认定 60 token 普遍更好。专名、同音字和“他/她”等转写差异不能直接视为发音错误，ASR 复核也不能替代人工听审。

## 实际分段机制与配置

上游 2.5-Pro 的 `infer_v2_5.py` 在文本归一化后按标点和 token 预算分段，逐段生成，段间拼接 200ms 静音。它不是将全文一次送入模型，也没有对跨段长程表现做额外微调。云端正常显存模式使用 120 token；8GB 本地显卡的低显存模式另有按约 40 字分段的分支，本轮没有验证那个分支。

120 和 60 都是文本 token 上限，不能直接当成汉字数。长文本使用 `max_mel_tokens=1500`，与前轮短句的 600 上限不同，这是为了给每段足够的生成空间。模型参数不变。采样参数仍是 top_p 0.8、top_k 30、temperature 0.8、num_beams 3；随机种子为 20261020 至 20261022。参考为前轮相同的 6.62 秒音频。

代码 `longtext.py` 通过上游流式接口记录每段音频，同时保留上游自动拼接的完整输出。没有降噪、音高修正或其他后处理。所有完整音频的长度均等于各段音频长度加段间静音，没有遗漏已生成的段。保存了完整输出、分段文本、分段音频和自动评分。

在原实验云端目录复现：

```bash
cd /root/voice-training/indextts25-mirror-20261010/repo
.venv/bin/python ../longtext.py synthesize
.venv/bin/python ../longtext.py score
.venv/bin/python ../longtext-asr-check.py
.venv/bin/python ../longtext.py package
```

权重与环境仍使用上一轮报告记录的版本。`checksums.json` 覆盖本轮云端原始结果；本地校验通过 60 个文件。包内包含脚本、参考音频、模型来源信息和截至评分完成的日志。复现时把脚本放到原实验 ROOT，迁移目录时更改脚本中的 ROOT。本轮新增结果在独立目录，前轮权重与默认引擎未改动。
