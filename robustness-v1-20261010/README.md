# 保留版 V1 扩展测试

当前 GPT 42 步和 CFM 84 步适配器已在本地及云端独立保存为 `mirror-joint-v1-20261010`，本轮没有继续训练。用户对此前音频的积极听感反馈作为保留这版的依据；自动指标与用户听感分开记录。

[打开对比试听](listening.html)。五类新文本包含技术说明、情绪对白与问句、更长故事、中文数字播报、多音字与连续问句；最长故事额外比较 60 token 分段。

## 结果解读

1518 字的新故事在默认分段下输出 301.5 秒，Whisper 逐段 CER 为 1.62%，SenseVoice 为 1.69%。底座同文分别为 1.69% 和 1.32%，差异很小且两套识别器给出的方向不同，不能据此认定联合微调普遍更准确。

60 token 版本输出 357.2 秒，两套逐段 CER 分别为 2.43% 和 1.84%。在这篇故事上较短分段没有显示更好的自动完整性，继续保留默认 120 token 作为当前对照设置。这里的“完整性”是识别代理指标，不是人工逐字认定。

数字播报两种模型的 SenseVoice 转写均与目标文本一致；Whisper 较高的原始 CER 包含阿拉伯数字写法差异及部分错字，不能解释为相同百分比的数字读错。技术说明、情绪对白和多音字的分数各有变化，本轮只验证这些固定文本、每篇一个种子，尚不足以建立全面的稳定性结论。当前保留版仍作为用户认可的试听基准；后续训练应根据具体听感问题补数据，再与本版比较。

Whisper turbo 使用中文、温度零、beam 五，并关闭跨窗口上下文，每个合成段单独识别；SenseVoiceSmall 独立复核全部十一条音频的每个分段，关闭数字逆归一化。CER 为各段字符编辑次数之和除以目标字符数之和，不包含标点。两套识别器可能有同音字、专名和代词的文字差异，不能把全部 CER 都视为合成发音错误。拼接转写与整篇原文的比对另保留在 `metrics.json` 的 `cer` 中。

“数字播报”原文已经使用中文读法，本轮没有验证阿拉伯数字、日期和单位的自动归一化。识别器可能把中文数字转写为阿拉伯数字，当前原始 CER 没有把两种写法转换成等价文本，因此数字播报的分数可能偏高，应核对转写和试听。情绪对白仅依赖文本标点与模型默认参考，并未设置情绪向量或强制情绪参数。多音字是否读对、问句语调和对白情绪是否合适需要人工听审；本轮没有人工听审。

所有完整 WAV 已验证为有效输出，并且 PCM 逐采样等于分段音频加 200ms 静音的拼接。这说明文件拼接完整，不代表模型一定准确读出每个字。`metrics.json` 和 `asr-diagnostics.json` 保留全部逐段原文、转写与编辑计数，方便检查具体疑点。

## 版本与复现

默认预算 120 文本 token，最长故事也比较 60 token；token 不等于汉字数。每段 `max_mel_tokens=1500`，段间 200ms 静音；top_p 0.8、top_k 30、temperature 0.8、num_beams 3。每个文本对照组使用相同种子（20261020 加文本序号）、参考和参数，没有后处理。云端 RTX 4090 的正常显存模式；没有验证本地 8GB 的低显存分段模式。

脚本 `robustness.py` 复用保存的 `longtext.py` 与 `experiment.py` 推理入口。启动前及打包前核验保留版哈希，同时比较正在加载的两套适配器与保留版。版本信息见 `preserved-version.json`；原版配置和适配器仍位于独立版本目录。

已经通过 `infer-preserved-version.py --version` 直接从保留目录加载两套适配器，第一轮首句音频逐采样复现成功。记录见 `preserved-version-inference-verification.json`，验证输出为 `preserved-version-reload.wav`。恢复入口支持明确指定版本目录、分段预算和生成上限，不依赖正在使用的训练目录。

在原云端 ROOT 运行 `repo/.venv/bin/python robustness.py all`，然后运行 `robustness-crosscheck.py`、`verify-preserved-inference.py`，最后运行 `robustness.py package`。重复执行前须修改 OUT 使用新目录，脚本拒绝覆盖已有实验。源码提交与底座哈希见 `provenance.json`。迁移目录时更改 ROOT；依赖与底座沿用第一轮环境。

从保留版本生成长文本：

```bash
repo/.venv/bin/python infer-preserved-version.py \
  --repo repo --models repo/checkpoints \
  --version versions/mirror-joint-v1-20261010 \
  --text '这里替换为需要生成的中文文本。' \
  --segment-budget 120 --max-mel-tokens 1500 --output new-output.wav
```

原始包 SHA256：`921ee9cf6ee503a04157d25a326f80167dc840337fa4e61873f33d3df460a867`。本地验证了 104 个云端文件、十一条完整音频及全部分段的 PCM 拼接。云端原始校验记录在 `checksums.json`，本地新增报告、试听及截图另行校验。
